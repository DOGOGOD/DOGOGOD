## A Little About Me

Hi, I'm **Guztchian**. I drift between technology and literature — describing the world with mathematics, reshaping it with code, and, now and then, trying to understand it with words.

A Software Engineering student at **Shanghai Jiao Tong University**, I'm drawn to AI, agents, and robotics — to the slow, stubborn craft of teaching machines to perceive, reason, and act. I'm equally captivated by mathematics, physics, and space, and by the quiet audacity of trying to understand the universe.

My [personal site](https://dogogod.github.io) is a notebook and a quiet place to land, where technical reflections, project notes, and small moments worth keeping find their way onto the page. If any of this resonates, you're always welcome there.

## Selected work

### [SJTUClaw](https://github.com/DOGOGOD/SJTUClaw)

A local AI agent runtime for personal and educational workflows. It combines multi-turn conversations, tool calling, long-term memory, Skills, scheduled tasks, and multiple interfaces — including desktop, Web UI, TUI, CLI, REST API, and QQ Bot.

<sub>AI agents · Local-first · Tool use · Memory · Multi-interface</sub>

### [Office Preview](https://github.com/DOGOGOD/Office-Preview)

An Obsidian plugin for previewing Word, PowerPoint, and Excel files without leaving your notes. It supports zoom, one-click text copy, multi-sheet navigation, automatic file routing, light and dark themes, and responsive layouts for desktop and mobile.

<sub>TypeScript · Obsidian API · DOCX · PPTX · XLSX</sub>

### [WeRead](https://github.com/DOGOGOD/WeRead)

A scheduled reading pipeline for WeChat Official Accounts. It collects recent articles, filters them by interest, extracts their content with Playwright, and turns them into personalized AI reading briefs.

<sub>Python · Playwright · Scheduling · AI summarization</sub>

### [MineSweeper](https://github.com/DOGOGOD/MineSweeper)

A cross-platform C++ Minesweeper built for the console, with full mouse support and colorful rendering. It includes flood-fill expansion, chord clearing, flags, first-click protection, custom grids, multiple difficulty levels, a timer, and sound effects.

<sub>C++ · Console graphics · Mouse input · Cross-platform</sub>
